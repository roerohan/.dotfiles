# Linux Configuration

This directory contains Linux-only desktop and system configuration retained from previous machines.

- `i3/`, `polybar/`, `rofi/`, and `nitrogen/` configure the desktop environment.
- `etc/` contains system-level files that must never be installed on macOS.
- `package_list.txt` is a historical Manjaro package snapshot, not a current installation manifest.

Shared terminal, editor, shell, Git, and agent configs remain at the repository root. The Ubuntu remote-box workflow uses [`../remote-box.sh`](../remote-box.sh).
